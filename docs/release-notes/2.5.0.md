groundwork 2.5 reorders the sidebar to follow how you work: write the code, run it, then look after what it built.

## What's new

- **The sidebar reads Overview, Code, Runs, Variables, Inventory, Graph, Troubleshoot, Notifications.** Code moved up from near the bottom, and Variables now comes before Inventory and Graph. The badges and when each page appears are unchanged: Graph still needs a Terraform root, Inventory an Ansible project, and Variables either.
- **New tutorial: [configure your Terraform hosts with Ansible](https://github.com/rapando/groundwork/blob/main/docs/tutorial-configure-hosts.md).** It takes three servers built with Terraform and configures them in groundwork: updates for every server, nginx on two web servers, and MySQL, Redis and RabbitMQ on a storage server, with the generated passwords passed from Terraform. It runs on Docker, so it needs no cloud account.

## Upgrading

```sh
curl -fsSL https://raw.githubusercontent.com/rapando/groundwork/main/install.sh | sh
groundwork service restart
```

Nothing in `groundwork.yaml` or your projects changes.
